# apps/web-studio: Web Studio (static, runs every engine in the browser)

**Purpose:** demo front end with no server and no build step; JS ports of every engine, verified against Python golden outputs.
**Base:** `revive-tery-web` (latest edit). `_reconcile_from_demo_front/` holds the pieces to port from `Revive-tery-demo-front` (DuckDB-WASM `lib/duckdb.js`, database/backend pages, `tools/convert_db.py`, WASM-readable DB copy); delete it once reconciled.
**Layout:** `index.html` · `assets/js/{app.js,engines/,pages/,ui/,lib/}` · `assets/vendor/` (JSZip, SheetJS) · `data/` (generated: models, configs, demo CSVs, reports) · `tests/` (+ `golden/`) · `tools/`.
**Rules:** `engines/*.js` are ports. Change the Python original first, then `just web-regen`. Never hand-edit `data/` or `tests/golden/` (generated). Pages and UI are free to edit. Plain JS ES modules only, no framework or bundler.
**Run:** `just web` then http://localhost:8080. **Test:** `just test-web` (41 parity tests).

**ML backend panels (optional, needs `just api` running):** `assets/js/lib/mlApi.js` (client; address in localStorage `revive.api.base`, default http://127.0.0.1:8000), `assets/js/ui/mlAdvice.js` (connection bar, how-the-ML-read-it table, needs form, advice view). Analyze page: "ML assistant: add a battery" sends files to `/api/intelligence/analyze`, stores the battery in the backend database and shows the advice. Circuit Studio: after a test ends, the monitored values go to the ML and the "ML suggestion" card shows 1 Recommendation (battery can go on) or 2 Suggestions (it cannot yet: inspect, fix data, recycle). Without the backend the pages say so and every in-browser engine still works.

**Upgrade (P7):** default route `#/command` (Command Center), `#/pack?id=` (pack detail with live what-if, passport, print), `#/live` (stage-by-stage assessment, Python parity badge), `#/history`, guided demo (`#/command?demo=1`, `ui/tour.js`). Data: `data/fleet_reports.json` (`node tools/make_fleet_reports.mjs`, in `just web-regen`), `data/db_meta.json` and `data/history.json` (`just web-db`); the live API (`/api/fleet`) is preferred when it answers. The database tables load in the background; pages that need them wait. Design: `assets/css/pro.css` (dark by default). Circuit: `ui/circuitView.js` from `data/circuit.json` (generated by `tools/wokwi_to_circuit.mjs`). Tests: `fleet.test.mjs`, `insight.test.mjs`, `firmware.test.mjs`, `circuit.test.mjs`, `fleet_db.test.mjs`.
