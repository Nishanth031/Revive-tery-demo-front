# Record a backup video of the guided demo

1. `just web` (and optionally `just api`), open `http://localhost:8080/#/command?demo=1` in a clean browser profile at 1920x1080.
2. Hide other windows and notifications. Set the OS to dark mode only if you want the same colours (the app is dark by default).
3. Start a screen recorder for the browser window (Windows: Win+Alt+R with Xbox Game Bar, or OBS "Window capture"; macOS: Cmd+Shift+5).
4. Press Play on the tour bar (it advances every 15 s) or use the right arrow at your own pace; narrate with docs/DEMO_SCRIPT.md.
5. On the what-if step, drag the tariff slider slowly across the break-even so the decision flip is visible.
6. Stop at "Model evidence". Keep the file next to the slides; check it plays offline before the presentation.
